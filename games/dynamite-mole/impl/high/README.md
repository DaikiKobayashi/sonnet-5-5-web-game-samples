# Dynamite Mole (high)

ダイナマイトで岩を吹き飛ばし、敵を倒して出口の梯子を目指すグリッド型アクション。素の JavaScript + Canvas 2D + Web Audio。ビルド・依存パッケージなし。

## 起動方法

```
cd games/dynamite-mole/impl/high
python3 -m http.server 5103
# ブラウザで http://localhost:5103/dist/index.html を開く
```

URL パラメータ: `?seed=<n>` `?stage=<1-5>` `?debug=1` `?mute=1` `?touch=1`(仕様書 2.5 節どおり)。

## 仕様の解釈と判断したこと

- **ステージクリアのボーナス加算**: 「遷移した瞬間にスコアへ加算」は、`stageClear` に入った瞬間と解釈した。`stageClear` 画面に出す `TIME BONUS` と、`snapshot().score` の値が一致する。
- **ゲームプレイ用 RNG** は run 開始時に作って使い続ける(3.3 節どおり)。敵の生成位置はレベル用 RNG のみで決まる。
- **タイトルの `snapshot()`**: 起動時に開始ステージを生成して返す。`?seed` がないときは、タイトルで見えるシードと、Enter で始めた run のシードは別の値になる(run ごとに新しい値を引く仕様どおり)。
- **入力バッファ**: 押された方向を 1 つだけ保持し、ステップ終了時に「バッファ > 押しっぱなしの最後のキー」の順で採用する。プレイヤーが死亡演出中に押したキーは無視する。
- **パワーアップ**: ステージをまたいで持ち越す。死亡ごとに 3.8 節の減少を受ける。
- **`godMode(true)`** は `debug` で切るまで run をまたいで有効なまま。
- **`snapshot().texts`** は「直近に描画したフレーム」の文字列。`x3` は小文字 `x` のグリフで描くため、そのまま `x3` を記録している(他はすべて大文字化)。ロゴはフォントのグリフから作っているため、タイトルでは `DYNAMITE MOLE` を 1 件記録する。`PRESS ENTER TO START` は点滅の消灯中も薄く描画し続ける(常に texts に載る)。
- **タッチ UI** は `pointer: coarse` または `?touch=1` で表示。ボタンは `pointer` イベントで、キー入力と同じ経路に流す。
- **タブが非表示**になったら `playing` 中は自動で `paused`(`pause` 効果音も鳴る)。
- **ゴーレムの被弾フラッシュ**は白色化した別スプライトを点滅させて表現。ゴーストは追跡中に目が赤くなる。
- 炎が消える直前(残り 0.1 秒)は縮小して描く(判定は変えない)。

## 既知の問題

- BGM の旋律はコード進行と乱数から自動生成しており、聴感は耳では確認していない(音量・エラーなしのみ確認)。
- 全 5 ステージを人手で最後まで遊び切ったわけではない(debug API で短縮して遷移を確認)。
- タッチ UI は実機ではなく Chromium 上のポインタ操作で確認したのみ。
