# Dynamite Mole (xhigh 実装)

ダイナマイトで岩を吹き飛ばし、敵を倒して出口の梯子を目指すボンバーマン系アクション。
仕様は `games/dynamite-mole/SPEC.md`。素の JavaScript + Canvas 2D + Web Audio、ライブラリ・ビルドなし。
画像・音・フォントはすべてコードで生成する自作(外部ファイルは `dist/favicon.png` のみ。これも自作スプライトから書き出したもの)。

## 起動方法

```
cd games/dynamite-mole/impl/xhigh
python3 -m http.server 5104
# ブラウザで http://localhost:5104/dist/index.html を開く
```

`npm install` は不要(`package.json` なし)。URL パラメータ(すべて任意): `?seed=<整数>` `?stage=<1〜5>` `?debug=1` `?mute=1` `?touch=1`。
`?debug=1` を付けると `window.__GAME__.debug`(SPEC 7.4 の検証用関数)が使える。`window.__GAME__.snapshot()` は常に使える。

操作: 矢印 / WASD で移動、Space / Z で爆弾、P / Esc で一時停止、R でリスタート、M でミュート、Enter で開始。
タッチ端末(または `?touch=1`)では画面下に十字ボタン・BOMB・PAUSE が出る。タイトル / GAME OVER / クリア画面はキャンバスのタップで進む。

## 仕様の解釈と判断したこと

- **ステージクリアのボーナス**: 「遷移した瞬間にスコアへ加算」を「stageClear に入った瞬間」と解釈。`snapshot().score` は stageClear に入った時点でボーナス込みになる。
- **`x3` の小文字 x**: 仕様の字形表は小文字 `x` を含むので、`x` だけは大文字化せず、`texts` に `x3` のまま入れる(他の文字は大文字化)。
- **タイトルロゴの `texts`**: ロゴは画像アセットなので、`texts` には描画の代わりに文字列 `DYNAMITE MOLE` を記録する(ロゴの字形はビットマップフォントから作っている)。
- **`snapshot()` の直前に 1 回再描画する**: 入力直後に読んでも `texts` が現在の状態と一致するようにするため。画面に見える内容は変わらない。
- **HUD の配置**: 文字を 2x で読みやすく描くため 3 行(SCORE / HI、TIME / STAGE、ライフ / BOMB / FIRE / SPD / SND)にした。5.4 節の「配置は自由」に従う。
- **移動の入力バッファ**: 「最後に押されたキー」を採用し、ステップ中に押されたキーは 1 つだけ覚えておく。覚えたキーが塞がっていて、かつもう離されているときだけ、押しっぱなしのキーへフォールバックする(タップで一瞬止まるのを避けるため。塞がっていて押しっぱなしなら仕様どおり動かず向きだけ変える)。
- **敵の最初の方向**: 進行方向がまだないので、移動可能な方向から一様ランダムに選ぶ(wander の手順の「逆を除く」は進行方向があるときだけ適用)。
- **炎の管理**: 1 マスに炎は 1 件。別の爆風が重なったら寿命を 0.5 秒に更新し、種類(中心 / 腕 / 先端)を合成する。`explode` は連鎖でも 1 個 1 回 `sfxLog` に残し、音は 50ms 以内の重複を 1 回にまとめる。
- **死亡時の位置**: ステップの途中で死んだら、その位置のまま演出する(復活で (1,1) に戻る)。
- **タイトルの地形**: タイトル中は開始ステージを生成して `snapshot()` に返す。run のシードは run 開始のたびに決める(`?seed` があれば常に同じ)。
- **debug 関数**: `teleport` が壊した岩と `clearBlocks` / `revealExit` はスコア加算なし。`clearBlocks` は崩壊演出を出さない。`killAllEnemies` / `spawnEnemy` は直後に出口の開閉判定も行う。
- **BGM とポーズ**: ポーズ中は `audio.bgm` を変えず、音量を 30% に下げる。ミュート中は BGM のスケジューリングも止め、解除すると続きから鳴る。
- **タブが隠れたとき**(Should): `playing` なら自動で `paused` にする。
- **スコアのカウントアップ**(S13 の一部)は作っていない。喜びポーズと出口が開く瞬間のフラッシュで S13 の「2 つ以上」を満たす。

## 既知の問題・注意

- 音はヘッドレス環境では聴けないため、鳴り方(音色・BGM の出来)は耳で確認していない。合成グラフのエラーがないこと、長さ・ピークが 6.3 節の範囲に入ることだけを実測した。
- 実機のタッチ操作は未確認(ポインタイベントとビューポートのみ確認)。十字ボタンは指を滑らせて隣のボタンへ移る操作には対応していない(ボタンごとに押し直す)。
- ステージ 5 は全体が暗い藍色のため、コウモリなど暗い色の敵は頭のランプの光の外ではやや見づらい(見分けはつく)。
- `snapshot()` は呼ぶたびに 1 フレーム分の再描画をする。1 ms 前後で、テストの高頻度な呼び出しでも負荷は小さい。
