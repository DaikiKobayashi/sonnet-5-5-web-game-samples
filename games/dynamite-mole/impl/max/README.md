# Dynamite Mole(ダイナマイト・モグラ)実装

`games/dynamite-mole/SPEC.md` に沿った実装です。素の JavaScript(ES2020)+ Canvas 2D + Web Audio だけで、
依存パッケージ・ビルド・外部素材はありません。絵・文字・音はすべてコードで自作しています。

## 起動方法

```
cd games/dynamite-mole/impl/max
python3 -m http.server 5105
# ブラウザで http://localhost:5105/dist/index.html を開く
```

- 公開物は `dist/` の静的ファイルだけです(`dist/index.html` がエントリ。参照はすべて `./` の相対パス)。
- URL パラメータ: `?seed=<整数>` `?stage=<1〜5>` `?debug=1`(`window.__GAME__.debug`)`?mute=1` `?touch=1`(仕様 2.5 節どおり)。

### 操作

| 操作 | キー |
| --- | --- |
| 移動 | 矢印キー / WASD |
| 爆弾 | Space / Z |
| 開始・リトライ | Enter(タイトルと結果画面では Space も可) |
| 一時停止 / 再開 | P / Esc |
| リスタート | R |
| タイトルへ(結果画面のみ) | Esc |
| サウンド ON/OFF | M |

タッチ端末(`(pointer: coarse)`)または `?touch=1` では、キャンバスの下に十字ボタン・BOMB・PAUSE を表示します。
タイトル・結果画面ではキャンバスのタップが Enter と同じです。

## 仕様の解釈と判断したこと

- **タイルの所属**: `round(x)`, `round(y)`(JS の `Math.round`。ちょうど 0.5 は切り上げ)。
- **入力**: 押されている方向キーを押した順に持ち、最後のものを採用。ステップ中に押した方向は 1 つだけバッファ(終了時にキーが離れていても 1 歩進む)。
  同じ方向に割り当てた 2 つのキー(W と ↑)は、両方離すまで押下扱い。キーリピートは無視。
- **tick 内の順序**: 3.13 節どおり。爆弾の設置は移動のあと(入力処理・移動・設置)。死亡演出のカウントダウンは手順 2 の中で進める。
- **敵 AI**: 最初の進行方向は「進行方向なしの wander」(移動可能な方向から一様)。ゴーストの追跡判定はタイル到達ごと(表示用の `chasing` も同じタイミング)。
  仕様どおり「逆走禁止 + 25% の徘徊」なので、追跡は確率的です(距離 6 から出発して 2.5 秒後に近づく試行は約 83%:`tools/sim-ghost.js`)。
- **炎**: 寿命 0.5 秒は「作られた tick から数える」。同じタイルに複数の炎があってもよい(描画は腕 → 先端 → 中心の順で重ねる)。
- **ステージクリア**: ボーナスは `stageClear` に入った瞬間にスコアへ加算(表示も同時)。クリア中は爆弾・敵を止め、炎だけ見た目のために消えていく(得点・被弾なし)。
- **ゴーレムのダメージ**: `hitT`(0.8 秒)中は追加ダメージなし。1 HP の敵は最初の被弾で死ぬ。
- **タイマーの警告音**: 残り 10 秒以下に入った瞬間に 1 回、以後ちょうど 1 秒ごと。
- **ハイスコア**: run の終了(gameOver / gameClear / R での放棄)時に 1 回だけ保存。`NEW RECORD!` は「更新前の保存値より大きく、かつ 0 より大きい」とき。
  `snapshot().hiScore` と HUD の HI は `max(保存値, 現在のスコア)`。
- **タイトルへ戻る**(結果画面の Esc): 新しいゲーム待ちの状態に戻す(スコア 0・ライフ 3・開始ステージを再生成。`?seed` がなければ新しいシード)。
- **`?seed`**: 整数(負数は 32bit に丸める)。不正値は無視して run ごとにランダム。`?stage` の範囲外・不正値は 1。
- **`texts`**: 点滅する `PRESS ENTER TO START` は「暗くなる」だけで毎フレーム描く(常に `texts` に入る)。
  タイトルロゴは画像ですが、自作フォントの字形から生成したものなので、`DYNAMITE MOLE` として `texts` にも登録しています。
  HUD のライフは小文字 `x` の字形(乗算記号)で描き、`texts` には大文字化された `X3` が入ります。
  結果画面・操作説明の桁揃え(`BEST  015000` など)は等幅描画で、文字列は仕様の例と同じ空白数です。
- **デバッグ API**: `teleport` で壊れる岩・`clearBlocks` / `revealExit` は得点なし・効果音なし。`godMode(true)` はタイムアップでも死なない(タイマーは 0 で止まる)。
- **乱数**: `Math.random()` は run のシード決定の 1 箇所だけ。パーティクルなどの演出には専用の決定的な乱数(`DM.fxRand`)を使うので、ゲームの結果に影響しません。
- **一時停止中の BGM**: 停止ではなく音量を約 22% に下げる(`audio.bgm` は変えない)。タブ非表示による自動ポーズでは `pause` 効果音を鳴らさない。
- **爆発音の重複**: `sfxLog` には 1 個ごとに残し、実際の再生だけ 50ms 以内の重複を 1 回にまとめる。
- **省いたもの**: HUD の BOMB/FIRE/SPD 小アイコン(A17 の Should。2 段の HUD に幅の余裕がないため)、スコアのカウントアップ演出
  (S13 は「喜びポーズ + 出口が開くフラッシュ + 紙吹雪」で満たしています)。

## 既知の問題・注意

- **音は耳で確認していません。** 効果音・BGM は、オフライン描画して「ピーク(効果音 最大 0.326、BGM 最大 0.192)・長さ・ループ長」を数値で確認し、
  再生中の状態(`unlocked` / `bgm` / `sfxLog`)を確認しただけです。曲の良し悪しや音色は評価できていません。
- ブラウザの自動再生ポリシーにより、最初のキー入力/タップまで音は出ません。タイトルで最初に押すキーがゲーム開始の Enter だと、タイトル曲は鳴らないまま始まります。
- 検証は Chromium(ヘッドレス)のみです。Firefox / Safari、実機の音・タッチは未確認です。
- ゴーストの追跡は仕様どおりの確率的な規則のため、距離 6 ちょうどから始めると 2 割弱の試行では近づきません。
- キャンバスの拡大率は小数を許すので、ウィンドウによってはドットの幅がわずかに不揃いに見えます(仕様どおり)。
- ステージ 5 は「ほぼ黒に近い藍色」の指定どおり床がとても暗いです(モグラは灯りで見えるようにしています)。
