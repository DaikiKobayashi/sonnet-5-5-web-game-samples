# Dynamite Mole (low)

## 起動方法

```
cd games/dynamite-mole/impl/low
python3 -m http.server 5101
# http://localhost:5101/dist/index.html
```

ビルド不要。依存パッケージなし。`dist/` がそのまま公開物(参照はすべて相対パス)。

URL パラメータ: `?seed=` `?stage=` `?debug=1` `?mute=1` `?touch=1`

## ファイル構成

- `dist/index.html` エントリ(タッチ UI の DOM と CSS を含む)
- `dist/font.js` 自作 5x7 ビットマップフォント(A18)
- `dist/art.js` スプライト・タイル・ロゴ・タイトル背景をコードで生成(A01-A20)
- `dist/audio.js` Web Audio による効果音と BGM の合成
- `dist/game.js` ルール・状態遷移・描画・入力・検証フック
- `dist/favicon.svg` favicon(A22)

## 作ったアセット

すべてコード生成(外部素材なし)。絵の 1 ドットは 2x2 px に統一(32x32 セル = 16x16 ドット)。

- フォント A18: 5x7 字形(A-Z 0-9 と記号)。アトラスを色ごとに生成して 1x〜7x 整数倍で描画。
- モグラ A01/A02: 4 方向 x 歩行 2 フレーム(右は左の反転)、死亡 4 フレーム(星が回る)。HUD 顔アイコン 16x16 (A17)。
- 敵 A04-A08: スライム 2、コウモリ 2、ゴースト 2 x 通常/追跡(赤目)、ゴーレム 2 + 白フラッシュ、死亡煙 3 フレーム。
- タイル A09-A12: 5 テーマ x (床 2、外壁、柱、岩、岩の崩壊 3 フレーム)。
- 出口 A13(閉 1、開 2)、ダイナマイト A14(3 フレーム、残り 0.8 秒未満で点滅加速)、炎 A15(中心・腕・先端 x 2 フレーム)、アイテム 4 種 A16。
- ロゴ A19(縁取り付き大文字)、タイトル背景 A20(洞窟・鍾乳石・結晶。蛍、歩くモグラ、上下するロゴで動く)。
- 効果音 15 種(矩形波/三角波/ノイズ)、BGM: title と stage1〜5 の計 6 曲(アルゴリズムで別々に生成、32 ステップループ、残り 30 秒以下でテンポ 1.25 倍)。
- 環境光: ランタンの揺らぎ、ビネット。パーティクル、スコアポップアップ、画面シェイク(reduced-motion では無効)。

## 仕様の解釈

- HUD は 3 行(高さ 14px の文字)に分けて配置。ラベルは仕様どおり。ライフは `X3`(小文字 x は大文字化される)。
- 炎の判定は、炎が出た tick の同 tick で爆弾の連鎖を処理。爆弾は 1 個ずつ `explode` を記録(音は 50ms 以内の重複を 1 回にまとめる)。
- ステージクリアボーナスは stageClear に入った瞬間にスコアへ加算。
- 敵の最初の進行方向は、生成時にゲームプレイ用 RNG から決める。
- 死亡演出中は時間・炎・敵・爆弾が進む。復活時の無敵は 2.0 秒。
- `godMode` はデバッグ用で、新しい run でも解除されない(ページを開き直すまで維持)。
- Should の「タブ非表示で自動ポーズ」は `visibilitychange` で実装。タイトルの主人公イラストは 1x のスプライトを並べて動かす(ドットサイズ統一のため拡大しない)。
