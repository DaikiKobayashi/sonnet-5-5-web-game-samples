# Dynamite Mole - impl/fable-high

ヘルメットのモグラがダイナマイトで岩を吹き飛ばし、洞窟の敵を倒して出口の梯子を目指すグリッド型アクション。
仕様書 `games/dynamite-mole/SPEC.md` に従った実装です。素の JavaScript + Canvas 2D + Web Audio、依存パッケージ・ビルドなし。

## 起動方法

```
cd games/dynamite-mole/impl/fable-high
python3 -m http.server 5107
# ブラウザで http://localhost:5107/dist/index.html を開く
```

`npm install` は不要です。`dist/` がそのままソース兼公開物で、参照はすべて相対パスです。

URL パラメータ(仕様 2.5 節): `?seed=<整数>` `?stage=<1-5>` `?debug=1` `?mute=1` `?touch=1`

## 仕様の解釈と判断したこと

- **`x3` の表記**: フォントの字形一覧に小文字 `x` が明示されているため、`x` は乗算記号の字形として扱い、大文字化しません(`snapshot().texts` には `x3` のまま入ります)。他の小文字は大文字に変換します。
- **ロゴの texts**: ロゴは起動時にビットマップフォントで画像に焼いたものを描画するので、タイトル描画時に `DYNAMITE MOLE` を texts に記録しています(`Font.note`)。
- **炎の重なり**: 複数の爆風が同じマスに重なった場合、同じ軸なら腕として繋げ、軸が違えば中心の絵にします。判定は「そのマスに炎があるか」だけです。
- **敵の被弾**: 炎に触れた敵は HP を 1 減らし、HP が残れば 0.8 秒の被弾後無敵に入ります。仕様どおり同じ炎(0.5 秒)で 2 回ダメージを受けることはありません。
- **タイムアップでの死亡**: godMode 中はタイムアップでも死なず、タイマーは 0 で止まります。
- **stageIntro の入力**: 方向キー・爆弾キーは無視し、intro 中に押した入力バッファは playing 開始時に捨てます(押しっぱなしのキーは playing 開始後に効きます)。
- **gameOver / gameClear のプロンプト**: `ENTER RETRY` などの行は最初から表示し、0.6 秒の入力ロック中は灰色で描いています。`NEW RECORD!` は点滅ではなく色を脈動させ、常に texts に入ります。
- **一時停止中**: `update` を呼ばず、累積時間も捨てます。BGM は発音中の音を止めて、再開時に同じ位置から続けます。
- **タブ非表示**: `playing` なら自動で `paused` にします(Should)。
- **ポート**: 実装識別子 `fable-high` の指定ポート 5107 を使います(仕様 2.3 節の表には effort 名しかないため)。

## 既知の問題

- 実際の音は耳で確認できていません(ヘッドレスで合成コードが例外なく走ることと、sfxLog・bgm の値だけ確認)。
- ゴーストのフレーム数は Must(2)どおりで、S11 の「各 3 フレーム以上」はゴーストだけ状態違い(通常/追跡)を含めての判定です。
- `prefers-reduced-motion` の実機切替は未計測(コード上で無効化)。
