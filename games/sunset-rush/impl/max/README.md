# SUNSET RUSH (impl / max)

夕焼けの海岸線から夜の街まで駆け抜ける、制限時間つきの疑似 3D アーケードレーサー。
Vanilla JavaScript(ES Modules)+ Canvas 2D + Web Audio、依存ゼロ・ビルドなし。`dist/` がそのまま実装のソースで公開物です。
画像・フォント・効果音・BGM はすべて自作で、コードから起動時に生成します(画像ファイル・音声ファイル・外部通信はありません)。

## 起動方法

```sh
cd games/sunset-rush/impl/max/dist
python3 -m http.server 5100      # ブラウザで http://localhost:5100/ を開く(ポートは任意)
```

- `npm install` 不要。エントリは `dist/index.html`。参照はすべて相対パス(`./js/main.js` など)なので、サブパス配信でも動きます。
- 検証用 URL パラメータ: `?seed=42`(乱数 seed 固定)、`?stage=1..3`(開始ステージ)、`?debug=1`(`window.__game.debug` と右下 FPS)、`?mute=1`、`?gallery=1`(アセットギャラリー)。
- 操作: `↑/W` アクセル、`↓/S` ブレーキ、`←→/A D` ハンドル、`Enter/Space` 決定、`P/Esc` 一時停止、`R` やり直し、`Q` タイトルへ(一時停止・ゲームオーバー)、`M` ミュート、`F` フルスクリーン。タッチ端末では画面に操作ボタンが出ます。

## 仕様の解釈と判断したこと

- **道路の描画**: 仕様 §3.4 のセグメント投影・遮蔽の手順どおり。ただし台形を多角形塗りにせず、**1 ピクセル行ごとに整数境界で矩形を塗る**方式にしました(継ぎ目・アンチエイリアスのにじみが出ない。§7.5 の要件を満たす手段)。丘の遮蔽は仕様どおり `maxY` で判定し、加えて「描く行を `maxY` より上に切り取る」「`maxY` は増やさず最小値を保つ」ことで、頂上の向こうの道路が手前の道にはみ出さないようにしています。
- **背景**: 空・遠景・近景を仕様のオフセット式(`k = 0.15 / 0.5 / 1.0`)で流します。地平線 y = 180 を地面色で先に塗り、フォグ(深度で道路・草・スプライトをステージ色へ溶かす)を掛けています。
- **スプライト**: 所属セグメントの `clipY` より下を切り取ります。カメラのすぐ手前(`camZ < 1.5 × CAM_DEPTH` のセグメント)のスプライトは描きません。左側の街灯だけ反転コピーを使い、腕が常に道路側を向くようにしています。
- **時間の進め方**: シミュレーションは固定 1/60 秒。カウントダウン(180 ステップ)、無敵(72 ステップ)、バナー(120)、GO!(48)、タイムアップ演出(150)、リザルト表示(90)などの持続時間はすべてステップ数で数えます。
- **走行距離点**: `playing` の間だけ加算します(ゴール後の自動減速やタイムアップ中は加算しない)。ゴール直後にスコアが確定するので、「ゴール直前の値 + 100 × floor(残り秒) + 1000」との差は距離点ぶんの小差だけです。
- **`stageclear` / `timeup` 中**: 運転入力は無効、衝突判定もなし(交通車は動き続けます)。
- **交通車の車種抽選**: 仕様の順序(seg → z → lane → 車種 → 速度)で抽選したあと、**先頭 8 台に 3 車種が必ず含まれるよう決定的に補正**しています(追加の乱数は使わず、同一 seed・同一ステージなら結果は同じ)。理由: seed 42 のステージ 1 で最初のスポーツカーが 1345 m 地点まで出ず、「30 秒走れば 3 車種が見える」(受け入れ基準 16)を満たしにくかったためです。
- **追従距離**: 仕様どおり同一レーンの前方 1000 u 以内で速度を合わせます。ワールド上では重なりませんが、遠景ではパースの都合で画面上の 2 台がやや近づいて見えることがあります。
- **路側物**: 位置は各セグメントの中央(`z = seg × 200 + 100`)。Should の solid #3(`rs_billboard` / `rs_signpost` / `rs_bollard`)と S3 の decor #2(`rs_building_b`)も出します(solid は各ステージ 3 種から一様抽選)。
- **タイトル**: ステージ 1 の世界を 7200 u/s で自動走行し、交通車の少ないレーンへ滑らかに移る自動運転で背景を流します(カメラが車を突き抜けないため)。操作説明の文字と重なるので、タイトルでは自車を描きません。末尾(`N + 40` セグメント)で先頭へ戻します。`getState().stage` はタイトルでは 1 です(開始ステージ `?stage=` は Enter/R で新しい run を始めた時に反映)。
- **`?mute=1`**: 起動時だけミュートにし、`localStorage` には書きません(`M` を押した時点の状態から保存)。
- **ミュート中の音**: マスターゲインを 0 にします(AudioContext 自体は動かし続けるので、解除すれば BGM は途中から聞こえます)。
- **音の最初のジングル**: 最初のキー入力が `Enter`/`Space` 以外のときだけタイトルジングルを鳴らします(決定キーではカウントダウンの音と重ならないように)。
- **一時停止**: `AudioContext.suspend()`。`R`/`Q` で抜けるときは先に `resume()` します。BGM のシーケンサーは AudioContext の時計で動くため、停止中は進みません。
- **blur / 非表示(S-15 と §4 の両立)**: どちらのイベントでも押下状態を全部クリアし、`playing` 中なら自動で `paused` にします。合成した `blur` イベントでも同じ動きです(押しっぱなしのまま加速し続けることはなく、車は停止した状態で止まります)。
- **HUD の位置**: 速度の数字は仕様の y = 322 の代わりに y = 316(`KM/H` は y = 346)にして、下端に収めています(±8px 以内)。進捗バーの旗は文字 `F` ではなくチェッカー柄の旗の絵です。HUD の上端には読みやすさのための薄い暗色のグラデーションを敷いています。
- **`NEW BEST!` / `PRESS ENTER`(タイトル以外)**: 完全に消えるとスクリーンショットで見逃しやすいため、点滅ではなく色または透明度の脈動にしています。タイトルの `PRESS ENTER` だけは仕様どおり 0.5 秒周期で明滅(暗いときも薄く残る)。
- **色調**: 各ステージの道路・草・路肩は 2 色ずつのペアで、輝度差(0〜255)は路肩 90 以上、道路 約 20、草 約 20 以上にしました。ステージ 3 の路肩はシアン/マゼンタのネオン。
- **`getState().audio`**: `state` は AudioContext の実際の状態、`bgm` と `engineHz` は仕様の scene 規則から算出(AudioContext が無くても値が決まる)。
- **画面効果(Should)**: 衝突で画面シェイク 0.3 秒・火花・白フラッシュ・自車の揺れ、チェックポイントで金色フラッシュ、250 km/h 以上でスピード線、夜ステージでヘッドライト・街灯/ネオンの発光・テールランプのにじみ、リザルトの数字カウントアップ、シーン切り替えのフェードイン(0.23 秒)、タイトルロゴの浮遊と輝き。

## 検証ツール(`tools/`)

Playwright はグローバルインストールを使います(`/opt/node22/lib/node_modules/playwright`)。ブラウザはクラウド環境の Chromium。

```sh
cd games/sunset-rush/impl/max
python3 -m http.server 5105 &                 # impl/max を配信(/dist/index.html を開く)
node tools/simtest.mjs                        # 物理・ルールの単体チェック(ブラウザ不要)
node tools/e2e.cjs [load flow physics render traffic stage misc audio input repro gallery should]
ONLY=15 node tools/e2e.cjs render             # 受け入れ基準の番号を絞って実行
node tools/bot.mjs 42                         # 自動運転ボットで 3 ステージがクリアできることを確認
node tools/perf.cjs                           # 1 フレームの描画コスト
node tools/sfxcheck.cjs && node tools/bgmcheck.cjs   # オフライン描画で音量・持続時間・拍を確認
```

## 既知の問題・制限

- **音は耳では確認できていません。** この環境にはオーディオ出力がないため、音の検証は「AudioContext の状態」「発振器の周波数」「シーケンサーの進行/停止」「オフライン描画したピーク・RMS・持続時間・拍の包絡線」まで(BGM のピークは −8 dBFS 前後、SFX は 0.2〜0.5)。曲の出来やミックスの聴感は未確認です。
- Chromium(ヘッドレス)でのみ検証しています。Firefox / Safari、実機のタッチ端末、実際のフルスクリーン表示は未確認です(タッチは CDP のタッチイベントでの確認)。
- スタートゲート(セグメント 8、仕様どおり)は、カウントダウン中は画面上部いっぱいに大きく見え、HUD と重なります(HUD には暗色のグラデーションを敷いて読めるようにしていますが、ゲートの絵は透けて見えます)。
- 遠くでは、同一レーンで追従している 2 台が画面上で近づいて見えます(ワールド上の間隔は 1000 u 以上)。
- `stageclear` / `timeup` の自動減速中は衝突判定がないため、後ろから来た交通車が自車と重なって見えることがあります。
- 時間が 100 ミリ秒以上かかるフレームが続く環境では、仕様どおりシミュレーションが実時間より遅く進みます。
- 合成した `blur` イベントでも自動一時停止が起きます(S-15 と §4 を両立させるための選択)。
