# SUNSET RUSH (opus-medium)

OutRun 風の疑似 3D アーケードレーサー。依存ゼロ・ビルドなし(`dist/` がそのままソース)。

## 起動方法

```sh
cd games/sunset-rush/impl/opus-medium/dist
python3 -m http.server 5100
# http://localhost:5100/ を開く
```

- サブパス確認: `impl/opus-medium/` を配信して `/dist/index.html` を開く(検証はこの形で実施)。
- 検証用パラメータ: `?seed=42` `?stage=2` `?debug=1` `?mute=1` `?gallery=1`

## ファイル構成

```
dist/
  index.html      canvas + CSS(16:9 レターボックス、pixelated)、タッチボタンの CSS。favicon は data URI
  js/main.js      エントリ(gallery=1 ならギャラリー、それ以外はゲームを動的 import)
  js/game.js      ゲーム本体(状態・入力・固定ステップのループ・投影描画・HUD・シーン・検証フック)
  js/course.js    ステージ表・セクション表、セグメント生成、seed 付き配置(交通車・路側物・ゲート)と layoutHash
  js/assets.js    全画像アセットをコードで生成(ピクセルバッファ → offscreen canvas)
  js/font.js      font_pixel(5x7 ビットマップフォント)と描画関数(色ごとにアトラスをキャッシュ)
  js/audio.js     Web Audio による BGM 3 曲・エンジン音・効果音の合成
  js/gallery.js   アセットギャラリー(?gallery=1)
```

## 仕様の解釈と判断したこと

- `maxY` の更新は仕様どおり `p1.screenY`。道路の台形は下端を 1px 伸ばして継ぎ目を防いでいる。
- カメラ位置 `pos` と同じセグメント(n=0、`p1.camZ ≤ CAM_DEPTH`)にあるスプライトは投影できないので描かない(画面より下に来る位置)。
- 追い越しと衝突の判定は同じステップで衝突を先に判定する(衝突した車には追い越し点が入らない)。符号反転は両方向(自車が抜かれる場合も)を見る。
- `countdown` 中の交通車は止めておく(開始時の配置を保つため)。`stageclear` / `timeup` 中は走り続ける。
- `debug.warp` は、通過済みのチェックポイントを `checkpointsPassed` にも数える(加算なし)。全交通車の前回相対 z を更新して、ワープで衝突が起きないようにしている。
- タイムアップとゴールが同じステップで起きたときはゴールを優先する。クリア時のボーナスは `floor(timeLeft)`(減算後の値)で計算する。
- 交通車の色違いは placement 時の seed 付き乱数で決めて、layoutHash にも含めている。
- 路側物の solid 3 種目・decor 2 種目(S3)も一様抽選の対象にしている(Should)。
- 路側物のゲートはスタート(セグメント 8)にも置いている(Should の gate_start)。
- タイトルでは自車がレーンを選んで交通車をよけながら自動走行し、ゴール手前で先頭に戻す(フェード付き)。衝突判定はない。
- ステージ 3 の夜の光(ヘッドライトの照射、テールランプ・街灯・ネオンの発光)は加算合成で重ねる。
- 煙は仕様どおり 12px を 2 倍(24px)で描く。
- 速度表示は `KM/H` を数字の下に置くため、数字を y=314 にした(±8px の範囲)。
- リザルトパネルは左ラベル/右寄せの値という列の並びにした(内容は §3.12 のとおり)。数字はカウントアップ表示。
- フォグは道路・草・路肩の色だけにかける(スプライトにはかけない)。

## 既知の問題

- スタートゲートがスタート地点のすぐ前にあるため、カウントダウン中は横断幕が画面上部の HUD と重なる。
- フォグはスプライトにかかっていない。
- タイトルの自動走行では交通車をすり抜けることがある(判定なし)。
- ステージ 3 の手前のビル(decor)は大きく、空の一部を隠す。
