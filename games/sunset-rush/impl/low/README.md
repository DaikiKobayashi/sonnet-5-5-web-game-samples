# SUNSET RUSH (low)

## 起動方法

```sh
cd games/sunset-rush/impl/low/dist
python3 -m http.server 5100   # http://localhost:5100/
```

ビルド・npm 依存なし。ギャラリーは `?gallery=1`、検証用は `?debug=1&seed=42&stage=2&mute=1`。

## ファイル構成

- `dist/index.html` エントリ
- `dist/js/main.js` ゲーム本体(コース生成・物理・交通車・描画・HUD・シーン・`window.__game`)
- `dist/js/assets.js` 画像アセットをコードで描画して生成(ビットマップフォント含む)
- `dist/js/audio.js` Web Audio による SFX / エンジン / BGM 合成
- `dist/js/gallery.js` アセットギャラリー(`?gallery=1`)

## 作ったアセット(すべて起動時にコードで描画・合成。外部ファイルなし)

- 画像(offscreen canvas にピクセル単位で描画): `font_pixel`(5x7、52 グリフ)、`logo_title`(232x50、斜体+グラデ+夕日)、
  `car_player` / `car_player_brake`(40x22 x3)、交通車 sedan/truck/sports 各 3 色(`_alt1`, `_alt2`)、
  路側物 13 種(palm, rock, shrub, pine, boulder, fern, lamp, neon, building, building_b, billboard, signpost, bollard)、
  ゲート 3 種(checkpoint, goal, start、160x64)、`bg_sky_1..3`(640x180)、`bg_far_1..3`(640x96)、`bg_near_1..3`(640x56)、`fx_smoke`(12x12 x4)。
  背景は水平にシームレス(整数周期の sin、折り返し描画)。
- 音: エンジン(saw+square→LPF、`60+140*sp` Hz)、bgm_1..3(ステージ別、128/138/150 BPM、8 小節ループ、ベース+リード+ドラム)、
  beep / go / checkpoint / crash / goal / timeup / menu / overtake / timewarn。

## 仕様の解釈と判断

- 描画は台形をスキャンライン(1px 行の fillRect)で塗り、継ぎ目とにじみを避けた。遠方は地平線色へフォグ。
- 交通車の色違い、ブレーキランプ、近景、スタートゲート、スレスレ得点、追い越しポップアップ、速度線、S3 のヘッドライト、フルスクリーン(F)、FPS 表示は実装。
  タッチ操作、砂煙/砂利音、火花、ジングル、blur 時の自動ポーズ、遷移フェードは未実装。
- 路側物の solid は各ステージ 3 種(Should の 3 つ目を含む)。
- ステージクリア・タイムアップ中も交通車は動く。カウントダウン中は交通車も止まる。
- タイトル背景は末尾近くでステージ 1 を作り直して先頭に戻す。

## 既知の問題

- タッチ操作なし。砂煙・砂利音・ジングルなし。
- 交通車の追従判定は同レーンの前方 1000u 以内のみ。ゴール後(stageclear)にも交通車が動き続ける。
- Chromium 以外は未検証。
