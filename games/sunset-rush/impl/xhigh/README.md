# SUNSET RUSH

夕焼けを追いかけて海岸線から夜の街まで駆け抜ける、制限時間つきの疑似 3D アーケードレーサー。
仕様書は `games/sunset-rush/SPEC.md`。JavaScript(ES Modules)+ Canvas 2D + Web Audio、依存ゼロ・ビルドなし。
画像・フォント・効果音・BGM はすべてコードで自作(外部素材・CDN・Web フォントなし)。

## 起動方法

```sh
cd games/sunset-rush/impl/xhigh/dist
python3 -m http.server 5104      # ブラウザで http://localhost:5104/ を開く
```

`npm install` は不要。エントリは `dist/index.html`。参照はすべて相対パス(GitHub Pages のサブパス配信でも動く)。

URL パラメータ(検証用): `?seed=<整数>` / `?stage=<1〜3>` / `?debug=1`(`window.__game.debug`・FPS 表示)/ `?mute=1` / `?gallery=1`(アセットギャラリー)。

操作: `↑`/`W` アクセル、`↓`/`S` ブレーキ、`←→`/`AD` ハンドル、`Enter`/`Space` 決定、`P`/`Esc` 一時停止、`R` やり直し、`Q` タイトルへ(一時停止中・ゲームオーバー)、`M` ミュート、`F` フルスクリーン。タッチ端末では画面下に操作ボタンが出る。

## 仕様の解釈と判断したこと

- **道路の描画**: 仕様どおりの投影式と手順。台形はスキャンライン(1 行ずつの矩形)で塗り、ピクセルに揃えて継ぎ目・隙間を出さない。手順 4-6 の `maxY = p1.screenY` は、丘の陰の判定が 1 セグメントぶん遅れて奥の道路が手前に食い込む場合があるため、`maxY = p2.screenY`(描いた道路の実際の上端)にし、描く行も `maxY` 未満に切り詰めた(見た目の式・スプライトの `clipY` の意味は仕様と同じ)。
- **フォグ**: 道路・草・縞・レーン線はセグメントの遠さ(n)に応じてステージのフォグ色へブレンド。スプライトは遠いほど透明度を上げて溶け込ませる(色ブレンドではなくアルファ)。
- **スプライト**: 仕様の式で描き、`z − pos < 100 u`(カメラ直前)のものは描かない。整数ピクセルに丸めて補間なしで拡縮。
- **背景視差**: `layerOffset += curve × (Δpos / SEG_LEN) × k`。空 0.15・遠景 0.5・近景 1.0。停止中は動かない。
- **タイトル**: ステージ 1 の世界を 180 km/h で自動走行(車体は描かない。プレイヤー X を ±0.35 でゆっくり振る)。末尾手前で先頭へ戻し、フェードでつなぐ。`PRESS ENTER` は 0.5 秒周期(0.35 秒表示・0.15 秒非表示)で点滅。
- **カウントダウン中**: 交通車は静止(GO! で動き出す)。`countdown` の運転入力は無効。
- **stageclear / timeup**: 交通車は動き続けるが、衝突・追い越し得点・距離点は入らない。ゴール後の距離は加点しない。
- **`getState().stage`**: タイトルでは「次に始まる開始ステージ」(URL の `stage`)。表示される背景は常にステージ 1。
- **`getState().score`**: 距離点を小数で積算し、状態と HUD は切り捨て。ゴール時の残り時間ボーナスは `100 × floor(timeLeft)`。
- **`warp(m)`**: `pos` を設定し、後ろの交通車を追い越し済みにし、通り過ぎたチェックポイントは加算なしで通過済み(`checkpointsPassed` は `max(現在値, 通過数)`)にする。得点・時間は動かさない。
- **衝突の細部**: 無敵時間は 72 ステップ(1.2 秒)。衝突判定は仕様の式(|相対 z| < 300 または符号反転、かつ横方向の重なり)。路側物の判定は交通車と同じ式。
- **スレスレ(S-07)**: 追い越しの瞬間に 180 km/h 以上で隙間が 0 以上 0.12 未満なら +20 点。
- **一時停止**: `paused` に入ると `game.step()` は何も進めない(タイマー・車・アニメ・煙・ポップアップも停止)。`AudioContext.suspend()` で音も止め、再開で `resume()`。
- **自動ポーズ(S-15)**: `blur` / `visibilitychange` は必ず押下状態をクリアする。そのうえで、`playing` 中に実際にフォーカスを失った(`document.hasFocus() === false`)または非表示(`document.hidden`)のときだけ自動で `paused` にする(合成イベントを投げただけでは止まらない)。
- **音**: `audio.bgm` は scene から決める(`countdown`/`playing`/`paused` は現在ステージの BGM ID、他は null)。`audio.engineHz` は `countdown`/`playing`/`stageclear`/`timeup` で `60 + 140×sp`、他は 0。ミュートはマスターゲインを 0 にする(BGM・エンジンは鳴らし続けるだけで無音)。初回のキー入力が Enter/Space 以外ならタイトルのジングルを鳴らす。
- **スタートゲート**: 仕様どおりセグメント 8 に置いたが、幅が道路の 1.3 倍あるためスタート地点ではほぼ画面の上に出てしまい、梁の信号ライトと看板の下端だけが見える。
- **検証用の補助**: `?debug=1` のときだけ、仕様の 4 メソッドに加えて読み取り専用の `debug.traffic()`(交通車の状態)と `debug.audio()`(マスターゲインなど)を置いた(自己検証用。ゲームの挙動は変えない)。
- **タッチ**: `(pointer: coarse)` のときだけ画面下に左右・アクセル・ブレーキと左端に一時停止ボタンを表示。タイトル・リザルト等はキャンバスをタップで決定、一時停止中のタップで再開。
- **フォント**: `.`〜`=` の記号は仕様の 15 種+空白。グリフ数は 52(最低ライン 50 以上)。

## 既知の問題

- 音を実際に聴いての確認はしていない(上記のレンダリング結果と `getState().audio` の状態のみ)。曲の好み・ミックスのバランスは未評価。
- `F`(フルスクリーン)は headless では検証できなかった。実機のタッチ操作・実際のウィンドウのフォーカス喪失による自動ポーズも未検証(エミュレーションと合成イベントでの確認のみ)。
- スタートゲート(`gate_start`)は幅が大きいため、スタート地点では梁の信号ライトと看板の下端が画面上端に見えるだけで、全体は画面に収まらない(仕様どおりの位置・サイズ)。カウントダウンの信号ライトと同時に 2 組の信号が見える。
- スプライトの遠方フォグは色ブレンドではなくアルファなので、遠くの車は道路が少し透けて見える。
- タッチ端末の横長画面では、右下のボタンが速度表示と重なる(ボタンは半透明)。
- ゲーム内の時間は仕様どおり 10 fps を割ると実時間より遅れる(1 フレーム最大 6 ステップ・実経過は 0.1 秒で丸め)。
- 交通車の追い越しでスレスレ判定を見るときなど、遠心力で横に流されるため、`setPlayerX` で正確な隙間を作るには衝突までの距離を短くする必要がある(検証スクリプト側の注意点で、ゲームの不具合ではない)。
